03 / getting started

Take the package for a first render.

Download the .tgz from GitHub Releases, then install it in your React application. The v0.2.0 release contains the package tarball.

Shell

pnpm add ./bench-design-0.2.0.tgz

TSX

import { Button } from 'bench-design';
import 'bench-design/styles.css';

<Button onPress={() => { /* application action */ }}>
  Continue
</Button>

Keep the local font assets beside the styles. Serve theme-init.js before CSS to restore the theme before first paint. Read the integration documentation for the full setup.
