# ActionCard

Import `ActionCard` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Use one whole-card target outside collections. Supply either `href` for navigation or `onPress` for an action. In a GridList, let the collection item own interaction instead. Use Card for content containing multiple controls.
Never put interactive or focusable elements in media or trailingIcon. Use presentational inline content (such as an image or Icon); avoid block elements inside the button. Keep media sized to fit narrow screens. The trailing icon is decorative; undefined uses an arrow for links, null hides it.

Use `layout="stacked"` for an eyebrow above the title and trailing content aligned to the bottom.

## Accessibility

The title supplies the accessible name; description is linked with aria-describedby. Media and eyebrow do not change the name. React Aria owns keyboard and pointer interaction: Enter follows links, Enter and Space activate actions. Disabled actions cannot activate or receive tab focus. Hover and visible focus add offset elevation without moving the card. Action buttons do not submit forms.

## Editorial entities

Use `variant="editorial"` for editorial title typography and `tone` for a category background from the theme tokens. `supportingText` adds a visible source or context label within the same card target; it does not create a second link. Applications own the label and destination.
