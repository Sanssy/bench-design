# AppShell

Import `AppShell` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Use for an application header, main content, optional side panels and footer. At widths of at least 960px and heights of at least 560px, the shell fills the viewport and each content zone scrolls independently. Shorter or narrower windows use natural page scrolling.

- Do use shared tokens and components for content inside each zone.
- Avoid overriding the scroll boundaries or nesting viewport shells.

## Accessibility

On large screens, keyboard focus follows DOM order: the main content first, then the start panel, then the end panel. Visual placement does not change this tab order.

Below 960px, main comes first, followed by a sticky single-selection panel selector and the selected panel. React Aria manages Tabs keyboard navigation and automatic selection: arrow keys move focus and select a tab. Each tab and tabpanel is linked with aria-controls and aria-labelledby. Supply start and end as optional objects with a meaningful label and content. Both panels remain mounted when switching selection or resizing; CSS hides the inactive panel on small screens and it is inert. At desktop widths both panels are interactive complementary landmarks. Use only one AppShell per page; supply headings in main and the header.
