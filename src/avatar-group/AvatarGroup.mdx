# AvatarGroup

Import `AvatarGroup` from `bench-design` and load `bench-design/styles.css` once.

## Usage and accessibility

Compose Avatar children and optionally cap the visible avatars with max. The +N indicator exposes the remaining full names to assistive technology. Avoid relying on position to identify a person.
