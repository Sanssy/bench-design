# Avatar

Import `Avatar` from `bench-design` and load `bench-design/styles.css` once.

## Usage and accessibility

The Person example uses an inline portrait illustration and a decorative avatar beside a visible name.

Use a full name for the accessible label. Initials use the first and last name; a failed image falls back to initials. Set isDecorative when an equivalent name is visible beside the avatar. Sizes are 24, 32 and 40 pixels. Avoid initials as the only accessible name.
