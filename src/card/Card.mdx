# Card

Import `Card` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Use for a static group of related content. Put actions inside the card rather than making the whole card clickable. Choose the semantic element for the document structure. Avoid selected or interactive card behavior; this API does not provide it.

Card uses soft content elevation in light contexts and no soft shadow in dark contexts. Keep hard offset elevation for actions and dialogs; it is not a card variant.

Use `media` for an edge-to-edge preview above the content. Provide alternative text for informative images. `padding` controls only the content spacing using existing spacing tokens. Choose `variant="outlined"` for a stronger border without a soft shadow; the default remains `raised`.

## Accessibility

This component has no keyboard interaction or added ARIA role. The as prop selects the native element; choose it for the surrounding document structure. Descendant controls keep their own keyboard behavior.
