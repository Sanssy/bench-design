# ComboBox

Import `ComboBox` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Use a visible label for a single searchable choice. Supply local `options` or
`loadItems` for server search. Keep product rules and network access in your app.
Do not use a placeholder as a label or this control for multiple choices.
Optional option descriptions appear on a second line.

Server requests receive `{ query, signal, cursor? }` and return
`Promise<{ items: readonly FieldOption[]; cursor?: string }>`.
Search starts 250 ms after the last input; the next input aborts the previous
signal. Forward it to your network request. No input cursor means the first
page; no returned cursor means the last page. Use stable unique identifiers
across pages. The list loads the next cursor as its end approaches.
The counter shows “N loaded” while more pages exist, then “N results”.
Local counts are exact. Errors offer “Try again”; empty searches suggest a
new query. Lists virtualize at 100 options and show at most seven 44 px rows.

Selection uses `selectedOption` / `onSelectionChange`, or `defaultSelectedOption`
for an uncontrolled field. Supply a full `FieldOption`, including its saved label.
The callback returns the option or `null`; form submission sends its `id`.
Saved choices need no additional server lookup.

## Keyboard and ARIA

Tab focuses the input. Type to search; Arrow Down opens and moves through options,
Enter selects, and Escape dismisses. React Aria owns focus, selection, validation
and label/help/error connections. Result updates use a polite live region.
Disabled options cannot be selected. Loading motion stops with reduced motion.
