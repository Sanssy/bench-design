# Composer

## Usage

Import `Composer` from `bench-design` and load `bench-design/styles.css` once.
Supply `label` and `onSubmit`; `hideLabel` keeps the accessible name. Choose controlled `value`/`onChange` or uncontrolled `defaultValue`. Submission preserves exact text and does not clear the field. The consumer owns delivery, clearing, errors and pending state. Keep conversation logic outside; placeholders never replace labels. Pending blocks edits and repeat sends; whitespace-only text cannot be sent. Send/Sending copy follows `BenchProvider`. Growth is bounded at six lines.

## Keyboard and ARIA

Tab reaches available controls with visible focus. Enter sends; Shift+Enter adds a newline. IME confirmation never sends. Labels/errors stay associated with the textarea. Pending is announced in a polite live region.
