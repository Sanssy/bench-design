# DisclosureGroup

Import `DisclosureGroup` from `bench-design` and load `bench-design/styles.css` once.

## Usage and accessibility

Group related Disclosure children. Expansion is exclusive by default; enable allowsMultipleExpanded when readers need to compare sections. Keyboard behavior belongs to each disclosure trigger.
