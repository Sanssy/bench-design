# DropZone

Import `DropZone` from `bench-design` and load `bench-design/styles.css` once.

## Usage and accessibility

Use for local file import. maxSize uses bytes. MIME types, wildcard MIME types and filename extensions are supported. Type refusals precede size refusals; valid files are delivered alongside refusals. A new selection clears old feedback. For a single-file zone only the first accepted file is delivered. Never use color as the only refusal signal. The visible message includes the filename and reason.
