# EmptyState

Import `EmptyState` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Use to explain an empty collection and a useful next step. Supply an action only when one is available. Choose the heading level for the surrounding document. Avoid using an empty state for errors or loading.
