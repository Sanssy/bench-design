# FileTrigger

Import `FileTrigger` from `bench-design` and load `bench-design/styles.css` once.

## Usage and accessibility

Native file selection from a visible Button. Use acceptedFileTypes to guide the picker; validate application constraints before processing files. Keyboard activation follows Button. Cancellation does not call onSelect.
