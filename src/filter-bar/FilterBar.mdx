# FilterBar

Import `FilterBar` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Compose a search control and FilterChip or FilterMenu children. The application computes resultCount and activeCount and clears its state through onClearFilters. Keep search and selections controlled: controls remount when crossing the 640 px breakpoint or reopening the mobile sheet.

Do use application state for applied filters. Avoid computing business filtering inside the design system.

Give the search control a label but no description or error message. Chips and the result summary align with the bottom of the search field, so text under the control would pull them away from its input. Put help text outside FilterBar, for example above the collection.

## Accessibility

Results are announced by a status region. Tab visits available controls; Enter and Space activate actions. The mobile Dialog contains focus; Escape, Close, and Show N results dismiss it and return focus to Filters N. Only one set of filter controls is mounted.

Internal copy and numeric summaries follow the React Aria locale. Use the optional `BenchProvider` for English/French copy and partial message overrides; consumer labels remain application-owned.
