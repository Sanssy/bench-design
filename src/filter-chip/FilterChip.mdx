# FilterChip

Import `FilterChip` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Use for an immediate boolean filter. Use controlled state when the application owns the selection. Avoid using a toggle for a filter with several values.

## Accessibility

Tab focuses the chip; Space or Enter toggles it. aria-pressed communicates selection; disabled chips do not activate.
