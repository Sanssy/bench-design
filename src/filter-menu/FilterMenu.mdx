# FilterMenu

Import `FilterMenu` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Use for several searchable filter values. Choices remain provisional until Apply; Clear applies an empty selection immediately. Dismissal cancels edits. Supply saved option labels through value or defaultValue. Use options for local search or loadItems for abortable server search after 250 ms, with cursor pagination. The chip displays the first two values and +N. The application owns filtering and counting. Avoid applying draft changes from the nested MultiComboBox onChange.

## Accessibility

Tab focuses the chip; Enter or Space opens the named dialog. Use arrows to navigate suggestions and Enter to select. Escape closes suggestions first, then the dialog; dismissal restores focus to the trigger. Apply and Clear are keyboard accessible actions.
Internal copy and numeric summaries follow the React Aria locale. Use the optional `BenchProvider` for English/French copy and partial message overrides; consumer labels remain application-owned.
