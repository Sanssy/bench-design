# GridList

Import `GridList` from `bench-design` and load `bench-design/styles.css` once.

## Usage and accessibility

Use for consumer-rendered cards or rows with stable string identifiers. Provide getKey when items have no string id. Keep readable text directly in renderItem for typeahead; opaque components cannot supply that text automatically. Provide selectionBar actions and renderEmpty content. Arrow keys navigate items; Tab enters internal controls. Enter activates before selection. React Aria toggle selection suppresses actions while a selection exists; Space selects. Avoid embedding a second independent selection control.

## Layout and selection

`columns` sets the maximum number of grid columns (default: 2). Columns fit the container using the panel-width token as a minimum, then collapse to one column on narrow screens. List layout remains vertical. Use positive integers.

`selectionVariant="strong"` uses the theme-aware strong selection tokens; `"accent"` keeps the default treatment. Item activation stays on GridList via `onAction`.

## Reordering

Provide `onReorder` to enable the six-dot drag handle. The callback receives string keys and a `{ key, position: "before" | "after" }` target. Apply that request to your own data; the DS does not change the collection. Provide `getItemLabel` for readable drag previews and announcements (Table otherwise uses its stable key). Select multiple items before dragging to move a group. Tree requests relative positioning, not insertion into a node; consumers own hierarchy validation.

Tab into the collection and reach the drag handle. Enter starts dragging, arrows move between insertion points, Enter drops and Escape cancels. React Aria supplies the live announcements. Keep the reorder capability stable: toggling whether `onReorder` exists remounts the Aria collection; control selection and expansion if they must survive that toggle.
