# Grid

Import `Grid` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Use for equal-width collections with two, three or four columns. Below 640px, every template uses one column.

`template="equal"` (or omitted) uses `columns`. Asymmetric templates override `columns`:
`hero` uses 7fr / 5fr, `sidebar` uses the 232px sidebar token / remaining space,
and `marker` uses the 136px marker token / remaining space / an auto-sized action.
Supply two children for hero/sidebar and three for marker. These templates preserve document order.

- Do choose spacing from the approved token scale; omitting gap adds no spacing.
- Avoid visual overrides or using layout to change reading order.
- For ul/ol, supply li children; section content should have an appropriate heading.

## Accessibility

Native document order is preserved. Layout has no keyboard interaction.
The as prop supports div, section, ul and ol. Provide valid children for the chosen element.
