# IconTile

Import `IconTile` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Use a square icon illustration beside a heading or item description. Choose `sm` (48 px) or `md` (64 px, default); the catalogue icon stays 24 px. Neutral uses a subtle surface, accent uses the primary accent, and category tones use subtle category surfaces. Avoid color-only meaning or using the tile as a button. Place actions in the surrounding control.

## Accessibility

Without `label`, the whole tile is decorative and hidden from assistive technology. With a nonempty label, it exposes one named image. Omit the label when adjacent text already conveys the meaning. The tile has no keyboard interaction or focus stop.
