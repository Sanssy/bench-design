# Link

Import `Link` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Use Link for navigation and Button for actions. Link inherits the surrounding
text color and remains underlined. Set `external` when opening a new tab.

- Do use meaningful link text describing the destination.
- Avoid “click here” and unexpected new tabs.
- Application routing, disabled links and distinct visited styles are outside this API.

## Accessibility

Tab focuses the link; Enter follows its destination. React Aria owns interaction
and keyboard focus visibility. External links use `noopener noreferrer` and
announce “(opens in a new tab)” to screen readers without displaying it.
An explicit `aria-label` should include the visible text; the external announcement
is appended to that name. Use `ref` to restore focus to the anchor.

Internal copy and numeric summaries follow the React Aria locale. Use the optional `BenchProvider` for English/French copy and partial message overrides; consumer labels remain application-owned.
