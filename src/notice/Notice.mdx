# Notice

Import `Notice` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Use for neutral, success, warning or danger feedback with a meaningful label. Never convey meaning through color alone. Neutral information uses text and a subtle surface; there is no info tone. Avoid interactive behavior in feedback labels.

## Spacing

Notice uses the consumer-owned `--bd-notice-padding-block` and
`--bd-notice-padding-inline` CSS roles. Each role independently falls back to
`--bd-space-16`, so the default remains uniform and follows the active theme.
Set either role on a wrapper to tune one logical axis without changing the
other. The compact example maps block spacing to `--bd-space-12` and inline
spacing to `--bd-space-16`; its local `--bd-space-16` remapping demonstrates
that the fallback remains scoped to the consumer wrapper.

Use the tone control and theme selector to inspect all tones in light and dark themes.

## Accessibility

Neutral, success and warning use role="status"; danger uses role="alert". The icon is decorative. Text uses the standard text token on tinted backgrounds. Neutral uses the standard border token on a subtle surface. The left border uses the existing strong token (4 px). No keyboard interaction is added. Use alerts only for messages requiring immediate attention.
