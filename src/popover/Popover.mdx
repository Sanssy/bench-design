# Popover

Import `Popover` and `Button` from `bench-design`; load `bench-design/styles.css` once.

## Usage

Use for contextual help anchored to a DS Button. Supply a meaningful accessible label and concise content. Avoid long tasks; use Dialog for them. This is a content dialog, not a menu or tooltip.

## API

<ManifestProps component="Popover" />

Placement defaults to `bottom start`. React Aria adjusts the preferred placement near viewport edges. No veil is rendered.

## Accessibility

The required label names the content dialog. Enter or Space opens it from the trigger; Escape or outside interaction dismisses it. React Aria manages focus and returns it to the trigger. Appearance respects reduced motion. Give meaningful names to any interactive content.
