# Ask with sources

Compose Page, AppHeader, TopNav, Heading, ActionCard, ActionList, Composer,
ReferenceList and Paper to show a question alongside its supporting sources.
The example uses fictional content and a local timer; it makes no network request.

## Application responsibilities

Own conversation state, answer generation, permissions, errors and source resolution
in the application. This local, unexported recipe is a demonstration, not a conversation service.
Use React Aria links for citations and provide real destinations in your application.
The highlighted excerpt uses native `mark` semantics.

## Keyboard and responsive use

Choose a suggestion to send it directly; suggestions remain available after the answer. Enter submits; Shift+Enter adds a line.
The Composer announces waiting and the answer region announces completion.
Tab reaches each citation, which links to the focusable source excerpt.
At narrow widths, numbered ActionList rows replace the suggestion cards.
Each send adds a question and answer while keeping earlier turns visible. Suggested questions receive sources and a final reserve; other questions show “Answer unavailable” with guidance and no citations.
The composer stays in normal flow until the first answer, then remains sticky during later sends. New answers scroll into view with space reserved for the composer.
Only its card sticks; the centered demonstration note remains in flow.
Use the theme selector to inspect light and dark appearances at 320 px and desktop widths.
