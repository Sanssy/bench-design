# Document library
An editorial import area, searchable collection and modal reading sheet composed entirely from shared primitives. Cards are static; GridList owns their activation.

Supply document data, categories, search policy, upload, extraction, persistence and routing. All documents here are fictional. Choosing files only displays filenames; it does not upload or add documents to the archive.

Tab to search, type a title, then Tab to the document-type controls. Arrow keys move between facets; Space selects. Tab into the collection, use arrows to navigate and Enter to open the reading sheet. Escape dismisses it and returns focus to the activated row. The sheet fills the viewport on small screens. Use the theme selector for light and dark presentations.
