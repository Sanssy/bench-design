# An overview of related records

Use an editorial title, a small domain selector and related records to explain a collection. Select Work to see the editorial empty state.

## Composition

AppShell and AppHeader provide landmarks; TopNav marks the current page. SegmentedControl wraps at most six counted domains. ActionCard is a single destination outside a collection, with a decorative IconTile and separate MetaList. ConnectedList keeps caller order, Timeline displays caller-provided dates, and Value displays amounts without calculating a budget. Surface inverse and Link inherit the active palette.

## Application responsibilities

Replace the fictitious data and fragment destinations. Applications own domain categories, counts, relationships, ordering, amount formatting and routing. This recipe only changes local example content; it does not infer facts from records.

## Keyboard, themes and reflow

Tab through the skip link, page navigation, domain selector and record links. Arrow keys move between domains; Space selects the focused domain. Enter follows links. Use the theme selector for light and dark; no theme is forced. Existing layout primitives collapse at narrow widths, including 320 px. Keep interactive elements outside ActionCard.
