# ReferenceList

Import `ReferenceList` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Use references in caller order with stable unique identifiers and a descriptive label. Supply href for navigable titles and description for optional context. Avoid using the list for source resolution or generated citations.

Use optional item `meta` for caller-owned end metadata, such as a page number.
Set `marker="accent"` for numbered accent tiles and ruled rows. The default
`marker="number"` preserves decimal list markers.

Use the theme selector to inspect light and dark themes.

## Accessibility

A named native ordered list provides visible numbering. Accent tile numbers are
decorative; the ordered list retains its semantics. Linked titles use the shared React Aria Link and support Tab focus and Enter activation. Unlinked references do not become focusable.
