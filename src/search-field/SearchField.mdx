# SearchField

Import `SearchField` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Supply a label. Use `hideLabel` when the surrounding context makes the purpose
clear; the label remains associated with the input. `variant="underlined"`
removes the frame while preserving keyboard focus and validation feedback.
Use `autoComplete` to provide a browser autocomplete hint. Use description for help and errorMessage for actionable
validation feedback. Required controls use native React Aria validation; optional
controls display “(optional)”. Use isInvalid for external validation.
Keep application rules in the consuming product. Do not use placeholders as labels.

## Keyboard and ARIA

Tab reaches enabled controls with visible focus. Type to search; Enter submits and Escape clears the value, and the clear button offers the same action by pointer.
React Aria connects labels, descriptions and validation messages. Disabled
controls cannot be edited or activated.
