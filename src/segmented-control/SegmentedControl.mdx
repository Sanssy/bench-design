# SegmentedControl

Import `SegmentedControl` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Use for a compact mandatory single selection. Every option needs a label, including icon options. The first enabled option is selected when defaultValue is omitted. Supply unique IDs and a valid controlled value.
Supply a meaningful label and concise help. Use actionable error messages.
Do not use color alone to communicate meaning. Choose controlled or uncontrolled
values for the lifetime of the component. Use the theme selector for light and dark.
For choice groups and sliders, validation is external via isInvalid and errorMessage;
isRequired does not introduce a native submit constraint.

Use `layout="wrap"` for up to six single-choice facets on narrow screens. Wrapped
segments have a minimum 44 px target and long labels break within the available width.
More than six options in wrap mode raises a RangeError. For larger facet sets or
multiple selection, use FilterBar and a filter sheet labelled “Filters N”.
An optional `count` appears after the label and is included in the accessible name,
including zero. The default inline layout remains compact.

## Keyboard and ARIA

Tab enters the group. Arrow keys move focus; Space or Enter selects. Disabled options are skipped.
In wrap mode, Right/Left follow option order across successive rows (reversed in RTL);
Space or Enter commits the focused choice.
Disabled controls cannot be edited. Help and errors are connected to the control.
