# Select

Import `Select` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Supply a visible label. Use description for help and errorMessage for actionable
validation feedback. Required controls use native React Aria validation; optional
controls display “(optional)”. Use isInvalid for external validation.
Keep application rules in the consuming product. Do not use placeholders as labels.

Use the theme selector to view light and dark examples, including invalid,
disabled and optional controls. Controlled and uncontrolled values are supported;
choose one mode for the lifetime of the control.

## Keyboard and ARIA

Tab reaches enabled controls with visible focus. Enter or Space opens the list. Arrow keys move, Enter selects, and Escape dismisses.
React Aria connects labels, descriptions and validation messages. Disabled
controls cannot be edited or activated.
