# SidePanel

Import `SidePanel` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Use inside an AppShell side zone, or as a standalone content panel. Its preferred width is the panel-width token (288px), with a 240px minimum and space-24 padding. Inside a bounded AppShell it scrolls independently. In a narrow AppShell it fills the selected tab panel.

- Do use shared tokens and components for content inside each zone.
- Avoid overriding the scroll boundaries or nesting viewport shells.
