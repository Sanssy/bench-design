# Status

Import `Status` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Use for success, warning or danger feedback with a meaningful label. Never convey meaning through color alone. Neutral information uses text and a subtle surface; there is no info tone. Avoid interactive behavior in feedback labels.

## Accessibility

The icon is decorative; the label conveys meaning. This component adds no live region and has no keyboard interaction.
