# Surface

Import `Surface` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Use raised for a content region and subtle for a supporting note. Choose padding from the shared spacing scale. A Surface has no border; compose headings and controls inside it. Avoid using a background tone to communicate success or failure.

## Accessibility

This component has no keyboard interaction or added ARIA role. The as prop selects the native element; choose it for the surrounding document structure. Descendant controls keep their own keyboard behavior.
