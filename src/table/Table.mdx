# Table

Import `Table` from `bench-design` and load `bench-design/styles.css` once.

## Usage and accessibility

Use for related data with named columns. Consumers reorder rows in response to onSortChange; sortDescriptor only represents sorting state. Use align="end" for numeric columns. Headings are sticky by default within the scrolling frame. Arrow keys move between rows and cells; Space selects and the selection checkbox supports select-all. Keep a meaningful row-header column first. Avoid using a table for unrelated card content.
