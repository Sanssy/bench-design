# Table

Import `Table` from `bench-design` and load `bench-design/styles.css` once.

## Usage and accessibility

Use for related data with named columns. Consumers reorder rows in response to onSortChange; sortDescriptor only represents sorting state. Use align="end" for numeric columns. Headings are sticky by default within the scrolling frame. Arrow keys move between rows and cells; Space selects and the selection checkbox supports select-all. Keep a meaningful row-header column first. Avoid using a table for unrelated card content.

## Reordering

Provide `onReorder` to enable the six-dot drag handle. The callback receives string keys and a `{ key, position: "before" | "after" }` target. Apply that request to your own data; the DS does not change the collection. Provide `getItemLabel` for readable drag previews and announcements (Table otherwise uses its stable key). Select multiple items before dragging to move a group. Tree requests relative positioning, not insertion into a node; consumers own hierarchy validation.

Tab into the collection and reach the drag handle. Enter starts dragging, arrows move between insertion points, Enter drops and Escape cancels. React Aria supplies the live announcements. Keep the reorder capability stable: toggling whether `onReorder` exists remounts the Aria collection; control selection and expansion if they must survive that toggle.
