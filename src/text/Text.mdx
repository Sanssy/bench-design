# Text

Import `Text` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Use paragraphs for reading and `as="span"` for inline content.
Size defaults to ui; label and mono always use meta size.

- Do use muted text for secondary information.
- Avoid label styling for long passages; it renders uppercase metadata.

Use `align="center"` for centered lines or `align="start"` for logical start alignment.
Omitting `align` inherits the surrounding text alignment. Use paragraph Text to align lines; inline spans follow the surrounding line layout.

## Accessibility

Native p/span semantics preserve reading order. Text has no keyboard interaction.
Label is visual metadata, not a form label; provide a native label for inputs.
