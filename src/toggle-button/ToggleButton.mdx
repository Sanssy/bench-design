# ToggleButton

Import `ToggleButton` from `bench-design` and load `bench-design/styles.css` once.
Use it for independent on/off view options. Supply a meaningful `label`; an optional
`icon` replaces the visible label while retaining the accessible name. Use Button
for a one-time action and SegmentedControl for mutually exclusive choices.

## TypeScript API

<ManifestProps component="ToggleButton" />

Choose `defaultSelected` for an uncontrolled initial state or `isSelected` with
`onChange` for application state. Keep one mode for the lifetime of the control.

## Keyboard and ARIA

Tab reaches enabled toggles. Enter and Space toggle the state; React Aria owns
`aria-pressed`, keyboard activation and visible focus. Disabled options cannot
be activated. Selected options reuse the SegmentedControl accent treatment.
