# Toolbar

A named horizontal group of related actions. Import `Toolbar` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Supply a descriptive required `label` and Button or IconButton children. Name every icon action. Prefer a simple Inline for unrelated controls. Do not add custom keyboard handlers. General `className` and `style` overrides are excluded.

## Keyboard and ARIA

Tab enters the action group; Left and Right arrows move between enabled actions. Home and End reach its boundaries. Enter and Space activate buttons. React Aria owns the toolbar role and keyboard behavior. Keyboard focus uses the shared visible focus treatment.
