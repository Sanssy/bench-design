# TopNav

Named navigation between pages. Import `TopNav` from `bench-design` and load `bench-design/styles.css` once.

## Usage

Supply a landmark `label`, unique item identifiers, destination labels and native `href` values. Set `currentId` from the application's current route. Omit it when no destination matches. Optional catalogue icons are decorative; counts are read with their destination label, including zero. Applications own count meaning, translations and routing.

Use TopNav for page destinations and Tabs for panels within one page. Do not replace native links with click handlers. No router dependency, `onNavigate`, `className` or style override is exposed. Links wrap into additional rows on narrow screens; long words wrap without hiding label text.

## Keyboard and ARIA

The navigation landmark has the supplied accessible name. The current link has `aria-current="page"`. Tab and Shift+Tab visit every link; Enter follows its native destination. Links retain browser context menus and modified-click behavior. Focus uses the shared visible outline. There are no tab or tabpanel roles and no custom arrow-key navigation.
